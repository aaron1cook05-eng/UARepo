Overview

This repository contains my coursework for Labs 1–3 of the Urban Analytics module. The assignment uses Python to explore and analyse data, create maps and investigate spatial patterns using different datasets and visualisation techniques.

Repository Contents

Assignment notebook: Contains the code, comments and outputs for the challenges completed across Labs 1–3.

Lab 1 Data: Datasets used for introductory Python, Pandas, raster and spatial mapping exercises.

Lab 2 Data: Datasets used for bike rental analysis, clustering and traffic sensor mapping.

Lab 3 Data: Datasets used for Dundee ward analysis, road crash analysis and large-scale taxi pickup visualisation.

Requirements
Libraries used include Pandas, GeoPandas, Rasterio, Matplotlib, Leafmap, Scikit-learn, HoloViews, Datashader, HVPlot and Colorcet.
Additional libraries may be required for individual challenges.



How to Run the Notebooks

Download or clone this repository from GitHub.

Open the assignment notebook in Jupyter Notebook or JupyterLab.

Ensure the required Python libraries are installed.

Make sure the datasets are available in the folders specified by the notebook file paths.

Run the notebook cells in order, starting from the beginning.

Relative file paths are used where possible so that the notebook can be run from the repository folder.
